# 打工薪資小幫手

使用網站：https://timlai3344777.github.io/payday-helper/

繁體中文、無建置步驟的響應式排班與預估薪資應用。延續奶油白與柔和綠色介面。

## 功能

- 新增、編輯、停用工作；僅工作名稱及正數時薪必填。
- 可選填預設上下班時間、隔日下班及不計薪休息分鐘。
- 桌面側邊面板、手機底部面板，同日多工作及分段班次。
- 以分鐘計算，月薪加總後顯示兩位小數；班次保留建立時的時薪。
- 明確的隔日下班選項與起訖日期，跨日薪資歸於開始日期月份。
- 編輯中的月薪即時預覽，取消還原，儲存才正式寫入。
- 時間重疊提醒、無效輸入提示、清除當日班表確認與刪除復原。
- JSON 備份匯出／匯入，格式驗證、覆蓋前確認、匯入後復原。
- 瀏覽器 localStorage 保存，支援前一版 JSON 備份遷移。
- 鍵盤操作、語意化標籤、減少動態效果偏好、手機視窗高度調整。

## 本機開啟

直接開啟 `docs/index.html`，或以靜態伺服器提供 `docs/`。

```sh
python3 -m http.server 4174 --directory docs
```

開啟 http://localhost:4174 。建議使用固定的網址與瀏覽器，避免資料分散在不同 origin。

## 驗證

不需要安裝套件，使用 Node.js 內建測試工具：

```sh
node --test tests/core.test.cjs
```

## GitHub Pages

將 `docs/` 內的 `index.html`、`style.css`、`core.js`、`app.js` 放到儲存庫 `docs/`。
在 Settings → Pages 選擇 Deploy from a branch，來源為 `main` 的 `/docs`，儲存後等待 GitHub Pages 建置完成。
此設定不需要 API 金鑰、後端或額外服務。

## 資料與計算說明

資料儲存在目前瀏覽器，不會自動跨裝置同步。清除網站資料、改用不同瀏覽器或切換網址，均無法直接存取原有資料；請先匯出 JSON 再於新網址匯入。

舊版 Sites 網址與 GitHub Pages 是不同 origin，請由原網站的「使用說明」匯出 JSON，在新版「備份與匯入」匯入。匯入舊版跨午夜班次時，會把舊有的隱含隔日設定轉成明確的隔日欄位。

預估薪資依已排班工時與時薪計算，未含加班加成、津貼及扣款。各工作小計與月薪都從未四捨五入的班次金額計算，畫面中的小計相加可能因顯示四捨五入而相差 0.01 元。

備份只包含工作及班表，不包含個人帳號或任何網站認證資料。GitHub Pages 公開部署的是應用程式碼，不會把使用者 localStorage 的班表上傳到儲存庫。
